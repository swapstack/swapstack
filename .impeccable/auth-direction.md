Scope: reusable native auth screens and session gates; Operate mode. Audience: developers integrating the kit and end users completing account tasks. Constraints: registry AuthProvider only, existing UI kit, mock coverage, no new visual identity.

## Direction contract

THESIS: Make each account task obvious and recoverable with one purpose per native screen, not a generic dashboard of auth cards.

OWN-WORLD: Existing neutral Swapstack tokens, platform system typography, safe-area screens, standard inputs and buttons, restrained semantic error/success states.

STORY: A user can sign in, create or recover an account, continue as a guest, upgrade later, and manage or delete the account without dead ends.

FIRST VIEWPORT: Safe-area task screen with title and concise guidance, vertically ordered fields, one primary action, secondary navigation below; profile centers identity before account actions.

FORM: Extension of the established native UI; stack navigation and familiar auth forms. seed: none (unavailable)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
