# Swapstack

Swapstack is a free Expo boilerplate where Supabase and RevenueCat will sit behind swappable adapters, so apps can change service providers without rewriting their core logic.

## Planned stack

- Expo, React Native, and Expo Router
- TypeScript
- Uniwind and Tailwind CSS
- TanStack Query
- MMKV storage
- Jest and React Native Testing Library
- Supabase and RevenueCat behind swappable adapters

## Work in progress

Swapstack is an early work in progress. The service adapters are not implemented yet, and the stack and APIs may change.

## Getting started

```sh
pnpm install
pnpm start
```
